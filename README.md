# QJ

我在南京大学读人工智能本科。

最近做了两个项目，一个帮客服查工单，一个用自然语言查电商数据。

我把测试样例和验收摘要也放在了仓库里。看代码时，可以对照实际跑出来的结果。

- **SupportFlow** · 客服在工单里查邀请失败的原因，主管批准后才能加临时席位，即使写入响应丢失也能按原动作查回执。[源码](https://github.com/NarrPat/SupportFlow) · [工单截图](https://narrpat.github.io/SupportFlow/)
- **DataPilot** · “上月买、本月退”的订单该算在哪个月？先明确销售和退款的统计口径，再由模型生成只读 SQL 查模拟电商数据。[源码](https://github.com/NarrPat/DataPilot) · [验收记录](https://github.com/NarrPat/DataPilot/blob/main/docs/verification.md)
